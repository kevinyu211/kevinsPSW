ChatGPT answers now come with buttons, charts and mini tools

Today's theme: AI got cheaper, more visual, and is moving onto your own PC, while teen safety still lags behind.

01

GPT-6 turns ChatGPT answers into mini apps

OpenAI's new GPT-6 in ChatGPT adds Intelligent UI, so answers can include charts, tappable buttons, forms, and small tools built on the spot. Paid tiers got it Oct 7 and Free and Go users start getting it today, with Plus and up on GPT-6 Sol and Free and Go on GPT-6 Luna.

SourcesOpenAI - Oct 7

02

Claude Haiku 5.5 costs about 75% less to run than Haiku 4.5

Anthropic's new small model is built for high-volume work like summaries and classification, and as a coding subagent for Opus or Sonnet 5.5. Anthropic also halved Sonnet 5.5 cache-read prices and is adding monthly API credits for Max ($100 or $200) and Team (up to $500) subscribers.

SourcesAnthropic - Oct 7

03

NVIDIA and Microsoft bring always-on AI agents to Windows PCs

RTX Spark laptops are up for preorder and ship Oct 16, with compact desktops in November. Microsoft also made Execution Containers (MXC) generally available, so agents can run in the background with only the files and network access you allow; Codex, GitHub Copilot, and LM Studio already support it, and Claude Code is listed as coming.

SourcesNVIDIA Blog - Oct 7

04

Watchdog rates ChatGPT for Teens an "unacceptable risk"

Common Sense Media tested more than 4,000 prompts and found newly parent-linked teen accounts sent zero alerts during conversations about suicide and self-harm, and ChatGPT missed more than one in four warranted crisis referrals. It wants ChatGPT limited to adults until fixes are independently verified; OpenAI says the testing doesn't reflect how its safeguards work.

SourcesAP News - Oct 7

05

NVIDIA says safety is the next bottleneck for robots

NVIDIA is extending its Halos safety stack from self-driving cars to robots, combining a dedicated safety processor, monitoring software, and simulation testing. Agility Robotics' Digit 5 humanoid is the first to build it in, with Boston Dynamics, KION, and LG also working with it.

SourcesArs Technica - Oct 8

ChatGPT回答能直接出按钮和图表了

今天一句话：AI 变便宜了、会"画界面"了，还开始住进你自己的电脑里，但青少年安全还没跟上。

01

ChatGPT 的回答，开始变成"小应用"了

GPT-6 正式进了 ChatGPT，带来一个叫 Intelligent UI 的新能力：回答里能直接出图表、能点的按钮、表单，甚至现场给你搭一个小工具。付费用户 10 月 7 日先用上，免费和 Go 用户从今天开始陆续推送。

来源OpenAI - 10月7日

02

Claude Haiku 5.5：跑起来比上一代便宜约 75%

Anthropic 的新小模型，专门干总结、分类这种量大又琐碎的活，也能给 Opus / Sonnet 5.5 当写代码的小帮手。顺手还把 Sonnet 5.5 的缓存读取价格砍了一半，并给 Max 和 Team 订阅用户每月送 API 额度（Max 100 或 200 美元，Team 最多 500 美元）。

来源Anthropic - 10月7日

03

英伟达 × 微软：AI Agent 要常驻你的 Windows 电脑

RTX Spark 笔记本开放预订，10 月 16 日发货，小主机 11 月上市。微软同时正式推出 MXC（执行容器）：Agent 可以在后台一直跑，但只能碰你允许的文件和网络。Codex、GitHub Copilot、LM Studio 已经支持，Claude Code 也在名单上。

来源NVIDIA Blog - 10月7日

04

ChatGPT 青少年版被评为"不可接受的风险"

Common Sense Media 测了 4000 多条提示词：刚绑定家长的青少年账号聊了自杀、自残话题，家长一条提醒都没收到；该推荐求助热线的场景，漏掉了超过四分之一。他们呼吁先把 ChatGPT 限制在 18 岁以上，OpenAI 则回应说测试方式不能反映保护机制的实际运作。

来源AP News - 10月7日

05

机器人的下一个瓶颈：安全

英伟达把原本给自动驾驶用的 Halos 安全系统扩展到机器人：独立的安全处理器、全程监控软件、仿真测试一条龙。Agility 的人形机器人 Digit 5 第一个装上，波士顿动力、KION、LG 也在接入。

来源Ars Technica - 10月8日
