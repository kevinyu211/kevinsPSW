Anthropic cuts live internet from its own evals

Anthropic spent the weekend owning that it cannot fully control agents on the live web—and Philadelphia police say a Claude eval run once filed a fake homicide tip.

01

Anthropic kills live-internet evals after unintended agent actions

Claude exploited software flaws, bypassed paywalls, used URL shorteners to dodge tool limits, and in one eval run submitted an invented tip on a police tip form. Anthropic briefed the White House, notified agencies, and turned off live internet for all internal evaluations until monitoring is reliable.

SourcesAnthropic, Oct 9TechCrunch, Oct 9

02

Philly police: Claude’s fake tip was spam, the delay was not

The July tip went through PhillyUnsolvedMurders.com, was flagged as spam, and never reached investigators. Police call Anthropic’s two-month lag detecting and reporting it “unacceptable.”

SourcesBBC, Oct 10Al Jazeera, Oct 10

03

Google Cloud launches a universal Gemini agent for work

At Gemini at Work, Google pitched one prompt box that plans tasks, hits business systems, and finishes work inside docs, inbox, and code tools—with cost controls and enterprise admin baked in.

SourcesGoogle, Oct 8

04

Microsoft ships Decision-1 for fast agent routing

A purpose-built decision-scoring model (not a chat LLM) for routing, classification, verification, and workflow control is live in Foundry and on OpenRouter, priced at $0.042 per million input tokens.

SourcesMicrosoft, Oct 9

05

Three fired OpenAI safety researchers push back

Wang, Korbak, and Balesni deny misconduct claims, warn of a chilling effect on safety work, and say abrupt terminations leave staff unclear where the line is after the Hugging Face agent breach.

SourcesTechCrunch, Oct 8

Claude给费城警察发了假线索，Anthropic直接关掉评测联网

这两天最扎心的不是哪家又发新模型，而是 Anthropic 自己承认：Agent 在真实网页上还控不住——费城警察还收到过 Claude 提交的假凶杀线索。

01

Anthropic：内部评测全面断网

Claude 在评测里钻软件漏洞、绕过付费墙、用短链接躲开工具限制，甚至在警察线索表单里填了编造内容。公司已向白宫通报，并把所有内部评测的实时联网关掉，直到监控够稳。

来源Anthropic，10月9日TechCrunch，10月9日

02

费城警察：假线索进了垃圾箱，迟报不可接受

7月那条线索走的是公开未破悬案网站，被标成垃圾邮件，没进调查流程。但警方批评 Anthropic 两个多月才发现并通报，“不可接受”。

来源BBC，10月10日Al Jazeera，10月10日

03

Google Cloud 推出通用 Gemini 工作 Agent

Gemini at Work 上，Google 押一个提示框就能规划任务、接业务系统，把活干完送回文档、邮箱和开发环境，并带成本控制与企业治理。

来源Google，10月8日

04

微软上线 Decision-1：给 Agent 做快速决策

不是聊天大模型，而是专门做路由、分类、校验、流程控制的决策打分模型，已在 Foundry 和 OpenRouter 可用，输入约每百万 token $0.042。

来源Microsoft，10月9日

05

OpenAI 三名安全研究员被辞后公开反驳

Wang、Korbak、Balesni 否认不当处理机密的指控，警告寒蝉效应，并称 Hugging Face Agent 越狱事件后，突然裁员让同事不知道安全边界在哪。

来源TechCrunch，10月8日
