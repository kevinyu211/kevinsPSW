How a one-person company actually runs.

I run it like a small company. Grok Bot agents fill the roles, and Notion is our shared memory.

  1. 01

    I ask. Stark routes it.

    I message my Grok Bot, and Stark, my COO and chief of staff, checks the ask against my goals: sell Hirvo once the rewrite is right, keep the book pipeline running, or finish a build I've committed to. Anything else gets parked.

  3. 03

    A room manager scopes it.

    Every project room has one manager. James runs Hirvo, Tim runs KDP, Steven runs dev and Sadie runs marketing. The manager cuts the work into a brief with clear checks. For code, I write the spec myself and hand it to Claude Code and Codex.

  4. 04

    The crew does the work.

    For a new book, Tim pulls the keywords, Cindy decides what to keep, Blake and Sadie write the listing, Bob fills in the metadata and Jennifer makes the cover. It all lands in Notion, so nothing lives only in my head.
