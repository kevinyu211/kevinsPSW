# city3d — the Transit city model library

Blender-made models for Kevin's metro city. Everything is generated by Python scripts, so the
library is repeatable and easy to extend.

    tools/city3d/build.sh

writes `designs/transit/models/kit.glb`, `landmarks.glb` and `manifest.json`, then renders proof
stills into `tools/city3d/previews/`. Needs Blender 5.x and Node.

| File | What it does |
|---|---|
| `atlas.py` | Draws the facade atlas: 16 window styles, one row each, repeating sideways. |
| `lib.py` | Modelling helpers (facades, roofs, beams, domes, text, screens), AO bake, mesh + material. |
| `kit.py` | 46 generic models: towers, mid-rise, low-rise, industrial, props. |
| `landmarks.py` | Kevin's tower, one headquarters per project, two station modules, the empty plot. |
| `build_all.py` | Builds every model, bakes AO, exports the GLBs. |
| `finish.mjs` | Checks the GLB node names against the manifest and writes `manifest.json`. |
| `preview.py` | Imports the exported GLBs and renders the proof stills. |

## Adding a building for a new project

1. Add a function to `landmarks.py` with `@lm('<project id>')`, named `hq_<project id>`.
2. Give it a screen with `m.screen(...)` so real project images can be shown on it.
3. Run `build.sh`. The model, its size and its screen appear in `manifest.json`.

## Conventions

- Metres. In glTF: Y up, front (entrance) faces +Z, origin at the footprint centre on the ground.
- One shared material (`city`): vertex colours (COLOR_0, ambient occlusion baked in) multiply the
  facade atlas. Screens use a second material (`screen`) and are child nodes named `<model>_screen`.
- Moving or tintable pieces are child nodes too: `<station>_canopy`, `k_tower_canopy`,
  `hq_nonstop_dome` (turns about the vertical axis), `plot_empty_jib` (turns about the vertical axis).
- Station rows in the manifest carry `rail`, `platform`, `length` and `trackClear` (metres).
