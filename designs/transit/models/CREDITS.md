# Model credits

Every model in `kit.glb` and `landmarks.glb` was made for this site with Blender 5.3, from the
Python scripts in `tools/city3d/`. No third-party meshes or textures are included.

- **Facade atlas** (embedded in both files): drawn by `tools/city3d/atlas.py`.
- **Lettering** on a few signs: Blender's built-in font (Bfont, a DejaVu Sans derivative, free licence),
  converted to plain geometry.

## Third-party kits considered, not used

- Kenney City Kit (CC0, kenney.nl): the download is behind a script-driven page, and the style is
  toy-scale, so it would not match real-proportion towers.
- KayKit City Builder Bits and Quaternius buildings (CC0): the same style mismatch.

If a third-party model is added later, list its name, author, URL and licence here.
