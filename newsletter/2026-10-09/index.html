Anthropic gives open-source maintainers free vulnerability scans

Labs spent Oct 8 pushing AI into cyber defense, enterprise agents, and small models you can actually run yourself.

01

Anthropic launches Cyber Mission for critical infrastructure and OSS

Anthropic opened a long-term defender program: Critical Infrastructure Defense Program with partners like CrowdStrike and Palo Alto, plus free OSS Scanner scans for enrolled open-source projects. Model-generated reports ship with a PoC and suggested fix, without human review first.

SourcesAnthropic, Oct 8

02

Google Cloud introduces the Gemini agent for work

At Gemini at Work 2026, Google Cloud announced a universal work agent that plans multi-step tasks, picks models, and finishes work inside docs, inbox, and dev tools—with enterprise admin and cost controls. Aimed at knowledge work through coding from one prompt box.

SourcesGoogle Blog, Oct 8

03

JetBrains open-sources Mellum2.1 coding-agent model

Mellum2.1 is a 12B MoE thinking model (2.5B active) under Apache 2.0. RL in real repos lifted SWE-bench Verified from 2.0 to 47.0; GGUF builds down to ~7–8 GB make local coding sub-agents practical.

SourcesMarkTechPost, Oct 8

04

Google open-sources ML Drift for on-device GPU inference

ML Drift is Apache 2.0 GPU compute for LiteRT across OpenGL ES, OpenCL, Metal, and WebGPU. It already powers Chrome, Photos, Shorts, and Meet; TFLite's old GPU delegate stops getting new features.

SourcesGoogle Developers Blog, Oct 8

05

Hugging Face Bio drops Carbon-A gene finder + huge annotation DB

Carbon-A (1.2B) predicts protein-coding regions from DNA across eukaryotes and helped build a database of 566 million gene candidates across 22,617 species. Wet-lab Iso-Seq checks back some novel predictions over RefSeq.

SourcesHugging Face Blog, Oct 8

Anthropic给开源项目免费扫漏洞

昨天这一波很实在：防黑客、企业 Agent、能自己跑的小编程模型，一起挤在 Oct 8。

01

Anthropic 开 Cyber Mission：保关键设施 + 免费扫开源漏洞

Anthropic 宣布长期「Cyber Mission」：一边和 CrowdStrike、Palo Alto 等一起做关键设施 OT 防护，一边给报名的开源项目免费 OSS Scanner。报告是模型直接出的，带 PoC 和建议补丁，先不经人工复核。

来源Anthropic，10月8日

02

Google Cloud 推出 Gemini agent：工作从一句话开始

Gemini at Work 2026 上，Google Cloud 发布面向企业的通用工作 Agent：会规划多步任务、选模型、连业务系统，最后把结果塞回文档、邮箱和开发环境，并带上企业安全和成本控制。

来源Google Blog，10月8日

03

JetBrains 开源 Mellum2.1：给编程 Agent 用的 12B MoE

Mellum2.1 总参 12B、每 token 激活 2.5B，Apache 2.0。主要靠真实仓库里的强化学习，SWE-bench Verified 从 2.0 拉到 47.0；还有约 7–8GB 的 GGUF，本地子 Agent 更现实了。

来源MarkTechPost，10月8日

04

Google 开源 ML Drift：端侧 GPU 推理底座

ML Drift 是 LiteRT 的新一代端侧 GPU 引擎，覆盖 OpenGL ES / OpenCL / Metal / WebGPU，已在 Chrome、Photos、Shorts、Meet 跑。旧 TFLite GPU delegate 不再加新功能。

来源Google Developers Blog，10月8日

05

Hugging Face Bio 发布 Carbon-A：从 DNA 找基因

1.2B 的 Carbon-A 直接从 DNA 预测蛋白编码区，并据此做出覆盖 22,617 个物种、约 5.66 亿基因候选的注释库；部分新预测已用 Iso-Seq 做了湿实验交叉验证。

来源Hugging Face Blog，10月8日
